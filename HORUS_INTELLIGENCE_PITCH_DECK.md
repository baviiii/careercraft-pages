## APPENDIX: TECHNICAL DEEP DIVE (BACKUP SLIDES)

### A1: Agentic Planning Architecture

**Query Decomposition:**
1. User asks complex question
2. GPT-4 function calling breaks into sub-queries
3. Each sub-query routed to appropriate tool (semantic search, graph query, table lookup)
4. Results synthesized with confidence scoring
5. Assertions validated against explicit rubrics

**Example:**
- Question: "What government investments will create healthcare jobs?"
- Sub-queries:
  * Query 1: Retrieve healthcare investment data (table extraction)
  * Query 2: Map investments to job creation programs (graph traversal)
  * Query 3: Identify skill requirements (semantic search)
  * Synthesis: "The $50M Health Innovation Fund will create 200 digital health roles requiring cybersecurity and data analytics skills (Confidence: 82%)"

---

### A2: Contradiction Detection Algorithm

**How It Works:**
1. Extract assertions from documents (entity-relationship triples)
2. Build knowledge graph of all assertions
3. Apply logical consistency rules:
   - Direct contradictions (A says X, B says NOT X)
   - Temporal conflicts (dates don't align)
   - Numerical mismatches (different funding amounts for same program)
4. Flag contradictions with severity scoring
5. Provide side-by-side comparison for manual review

**Use Cases:**
- Regulatory reform (identify outdated policies)
- Budget reconciliation (catch mismatched allocations)
- Policy compliance (ensure consistency across departments)

---

### A3: Data Provenance & Trust Model

**Every Insight Includes:**
- Source document(s)
- Page number or section reference
- Extraction method (table, text, metadata, chart)
- Confidence score (0-100%)
- Validation status (validated, needs review, low confidence)
- Timestamp of extraction

**Government-Grade Confidence Thresholds:**
- 75%+ to assert as fact
- 50-75% to mention as possibility
- Below 50% flagged for human review

**Audit Trail:**
- Full query and result logging
- User interaction tracking
- Document version control
- Change history
