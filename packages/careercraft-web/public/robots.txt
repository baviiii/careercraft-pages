# Faircopy — crawler policy
#
# Search engines and link previews: welcome, we want to be found and shared.
# AI search bots: welcome too. They fetch a page to answer someone's question
# and link back to it, which is the same deal a search engine offers.
# AI training crawlers: not welcome, they take the content and give nothing back.
#
# Most AI companies run these as separate bots (OpenAI: OAI-SearchBot vs
# GPTBot; Anthropic: Claude-SearchBot vs ClaudeBot), so we can allow one and
# block the other.
#
# This is a request, not a lock — a crawler that ignores robots.txt is not
# stopped by it. It works on the ones that behave, which is most of them.
