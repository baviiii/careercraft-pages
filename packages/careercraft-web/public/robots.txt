# CareerCraft — crawler policy
#
# Search engines and link previews: welcome, we want to be found and shared.
# AI training crawlers: not welcome, they take the content and give nothing back.
#
# This is a request, not a lock — a crawler that ignores robots.txt is not
# stopped by it. It works on the ones that behave, which is most of them.

Allow: /

Allow: /
